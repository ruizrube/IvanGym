# AGENTS.md

## Project overview
IvanGym is a mobile-first, offline-capable web app (PWA) for Iván's gym routine: 3 flexible routines, per-set weight logging, extra activities (cardio, walking…), history calendar and progress charts. UI language is Spanish. See `docs/PLAN.md` for the full spec.

It is plain HTML, CSS and JavaScript (ES modules) with **no build step**, deployed to GitHub Pages ("Deploy from branch", `main`, root). Data lives in `localStorage` (`ivangym:v1`) with JSON export/import.

## Structure
- `index.html` – shell (top bar, `<main id="view">`, bottom tab bar, dialog, toast).
- `js/app.js` – hash router (`#/hoy`, `#/dia/YYYY-MM-DD`, `#/historial[/YYYY-MM]`, `#/progreso[/exId]`, `#/ajustes`) and views.
- `js/data.js` – routines, exercises (muscles, tips, YouTube URLs), activity types, motivational quotes.
- `js/storage.js` – localStorage model, history queries, export/import.
- `sw.js` – service worker (precaches app shell and GIFs). **Bump `VERSION` and update `SHELL`** when adding/renaming static files.
- `img/exercises/*.gif` – generated by `tools/crop_gifs.py` from the collages in `docs/`.

## Working rules for agents
- Keep changes small and focused on the task.
- Do not introduce frameworks, bundlers or npm dependencies.
- Use relative paths only (the site is served under `/<repo>/` on github.io).

## Local development
- Serve the folder: `python3 -m http.server 8000` and open http://localhost:8000
- Regenerate GIFs (needs Pillow): `python3 tools/crop_gifs.py`

## Coding conventions
- Use 2-space indentation, LF line endings, no trailing whitespace, final newline.

## Validation
- Check the affected screen in a mobile viewport in the browser (DevTools device mode).
- Check the browser console for errors; test offline mode after changing `sw.js`.
